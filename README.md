# كلمتك ثابتة — Text Match Cut بالعربي المصري

نسخة Web عربية RTL لتأثير تثبيت الكلمة داخل قصاصات صحفية متحركة.

## المميزات

- واجهة عربية مصرية كاملة باتجاه RTL.
- قوالب نصية مصرية جاهزة.
- توليد الفيديو داخل المتصفح باستخدام Canvas وMediaRecorder.
- دعم المقاسات 9:16 و1:1 و16:9.
- إعدادات سرعة القصّات والزووم والطمس.
- أصوات مولدة داخل المتصفح: تقليب ورق أو كاميرا أو بدون صوت.
- معاينة وتنزيل WebM، وMP4 عند دعم المتصفح له.
- لا يحتاج تسجيل دخول أو Backend.

## التشغيل المحلي

افتح `index.html` مباشرة، أو شغّل خادمًا ثابتًا:

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## النشر

المشروع مصمم للنشر على GitHub Pages من فرع `main` ومجلد الجذر `/`.

## ملاحظات

الرندر يعتمد على إمكانيات المتصفح. أفضل تجربة تكون على Chrome أو Edge حديث، وقد يظهر WebM بدل MP4 في بعض المتصفحات. الخطوط العربية يتم تحميلها من Google Fonts عند وجود اتصال بالإنترنت، مع fallback محلي.
